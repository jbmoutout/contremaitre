CLI Review Loop — Detail
Security Boundaries
⬡ HOST-OWNED
Git credentials · GITHUB_TOKEN · GH_TOKEN · gh pr create · gh pr comment · push · commit-status projection. Never forwarded into any container.
⬡ DOCKER (locked egress)
Agent · SIM · CLI reviewer run inside per-role containers behind an allowlist proxy (OpenAI / Anthropic / OpenRouter / OpenCode Zen endpoints only). ANTHROPIC_API_KEY / OPENAI_API_KEY scrubbed. Reviewer additionally stripped of any GitHub token.
Per-Round Flow
Repeats for round = 1 .. max_cli_review_rounds. Exits early on first LOOKS_GOOD.
1
HOST Write /review bundle
Host writes extras/cli_review_NNN/input/ containing:
diff.patch · changed_files.txt · SETTLED_DESIGN.md · pr_body.md · pr.json · PR.md · head_sha.txt · previous_cli_reviews.md
2
DOCKER CLI Reviewer (codex / claude)
Locked egress · /review:ro · /app:ro
Reads the bundle. No gh calls. No GitHub fetch.
Returns markdown with verdict on line 1: LOOKS_GOOD NEEDS_ATTENTION MUST_FIX
3
HOST Post PR comment + commit status
gh pr comment <url> --body-file review.md
gh api .../statuses/{sha} — MUST_FIX → failure, else success
4
Verdict decision
LOOKS_GOOD → exit loop → READY_FOR_DRAFT_PR
NEEDS_ATTENTION → trigger revision ↓
MUST_FIX → trigger revision ↓
5
DOCKER CLI Revision (agent, fresh session)
Guard: IMPLEMENTATION_COMPLETE must exist.
Prompt prefixed [CLI] with ## Required changes items extracted from review.
Agent addresses changes in the worktree.
6
HOST Revision Gates
Commit · diff scan · diff hash stability · clean worktree · re-run --check-cmd
PASS → git push origin HEAD:<branch> → next round
FAIL → PR_NEEDS_HUMAN (PR stays, push skipped)
!
Max rounds exhausted
After max_cli_review_rounds without LOOKS_GOOD → PR_NEEDS_HUMAN
PR is already published. Human reviews before merging.

Terminal Verdicts
READY_FOR_DRAFT_PR
PR published. CLI reviewer reached LOOKS_GOOD (or was skipped). Safe to review and merge.
PR_NEEDS_HUMAN
PR published but CLI review loop exhausted max rounds without LOOKS_GOOD, or a post-publish revision couldn't safely push. Human must review before merging.
NO_PR_CHANGES_REQUESTED
SIM reviewer requested changes across all review rounds. No PR created.
NO_PR_NEEDS_HUMAN
SIM flagged NEEDS_HUMAN (agent violated a design constraint, or hard gate failed). No PR created.
QUOTA_EXHAUSTED
Provider free-tier quota hit (e.g. opencode-zen daily limit). No PR. Eval canary aborts the full n=3 batch.
FAILED_INFRA
Docker daemon error, SIGTERM, unexpected exception. Infrastructure-level failure unrelated to code quality.
